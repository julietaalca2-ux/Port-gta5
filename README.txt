Mods for GTA V on PC work here as downloaded. Put each file at its game path, like OpenIV's mods folder:
  x64e.rpf/levels/gta5/vehicles.rpf/adder.yft  (replaces a car)
  update/x64/dlcpacks/mycar/dlc.rpf  (an add-on car; added to the game automatically)
  common.rpf/data/handling.meta  (replaces a data file)
  MyMod.oiv  (an OpenIV package, installed as OpenIV would)
  Trainer.asi  (a Script Hook V script; its keys are under Mod keys in the game)
Cars, skins and add-on packs need the game files on this iPhone. Mods are read when the game starts.
Mods can cause crashes and glitches we can't fix: ask in the Mods topic on Telegram.
Guide: https://fivestarport.site/mods/
